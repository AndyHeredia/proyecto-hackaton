# Proyecto Hackatón

## Requisitos previos
- Tener instalado [Node.js](https://nodejs.org/) (v18 o superior recomendado).

## Instalación y ejecución rápida

1. **Clonar el repositorio:**
   git clone <URL_DE_TU_REPO>
   cd proyecto-hackaton

2. **Levantar el Backend:**
   cd backend
   cp .env.example .env
   npm install
   npm run dev

3. **Levantar el Frontend (en otra terminal):**
   cd frontend
   npm install
   npm run dev
